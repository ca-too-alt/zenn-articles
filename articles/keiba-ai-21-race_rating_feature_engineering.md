# 1. 概要

前回の第20話では、モデルの「過信」を数学的に矯正し、投資の正確な物差しを手に入れるために**3分割物理隔離**と**確率校正（Calibration）**を実装しました。これにより期待値（EV）運用の土台は整いましたが、検証の結果、モデルの根本的な「実力序列の予測精度（識別能）」、すなわち **Spearman 相関係数** が伸び悩んでいるという課題が浮き彫りになりました。

今回は、競馬のドメイン知識を凝縮した新規特徴量の投入と、学習崩壊という深刻なバグの克服プロセスを詳述します。

# 2. 実装内容

今回の開発では、単なる集計値を超えた「レースの文脈」と「数値的安定性」を両立させるため、以下の3軸を実装しました。

### 2-1. ドメイン知識に基づく新特徴量とモデルの2層分離設計
「レースの格」を数値化した `race_rating` や、昇降級を捉える `class_change_score` などのドメイン特徴量を導入しました。
$class\_change\_score = race\_rating_{current} - race\_rating_{previous}$
さらに、システムを「実力重視のランキングモデル」と「市場乖離重視の穴馬モデル」の2層に分け、それぞれに最適な情報を与える設計を採用しました。

### 2-2. rank_xendcg を用いた連続値リレーション学習
着順そのものだけでなく、走破タイム偏差に基づいた微細な実力差を学習させるため、目的関数に **rank_xendcg** を採用しました。これにより、従来の整数ラベルではなく、パフォーマンススコアに基づく連続値をターゲットとして扱えるようになります。

### 2-3. 時系列検証環境下での効率的な学習プロセスの構築
学習の過学習を抑えつつ効率を最大化するため、時系列分割された検証データを用いた **Early Stopping（早期終了）** を導入しました。

# 3. 遭遇した問題

実装を進めた結果、以下の3つの致命的な問題が発生しました。

### 3-1. 多重共線性によるノイズ混入と Spearman 相関の急落
新規に投入した14列のパフォーマンス系集計列が、既存特徴量と **多重共線性** を起こしました。また、ランキング用の「安定性指標」が穴馬モデルに混入したことで、穴馬モデルが「大敗からの激走」というエッジを捉えられなくなり、全体の識別能（Spearman）が劇的に後退しました。

### 3-2. 指数的な利得計算による勾配爆発と RMSE 18兆超
`rank_xendcg` を導入した直後、学習ログの RMSE が **18兆超（1.85965e+13）** という天文学的な数値を記録しました。原因は、内部計算式 $Gain = 2^{rel} - 1$ において、ターゲットラベルのスケールが不適切であったため、利得が指数爆発しモデルの重みが発散したことにあります。

### 3-3. 分布ドリフトによる Early Stopping の機能不全（Round 1 停止）
検証データの分布が訓練データと微妙に異なる「分布ドリフト」が発生し、学習開始直後（Round 1）に valid rmse が上昇して学習が停止する現象が多発しました。これにより、モデルが何も学習していない「定数出力」の状態に陥りました。

# 4. 解決アプローチ

これらの問題を解決するため、以下の「引き算」と「正規化」のデバッグを断行しました。

### 4-1. ranking_only_cols による特徴量空間の多層分離
穴馬モデルにとってノイズとなる着順系・安定性系指標（17列）を **ranking_only_cols** として定義し、穴馬モデルの入力から物理的に隔離しました。
- **Ranking専用**: `ewma_rank`（指数平滑移動平均）, `form_consistency`（安定度）など
- **共通**: 市場の過小評価を捉える市場乖離指標

### 4-2. ターゲットラベルの頭数正規化と target_alpha 制限
勾配爆発を防ぐため、ターゲットラベル $rel$ を出走頭数 $N$ で除算し、$0 < target \le 1$ の範囲に収まるよう **線形正規化** を施しました。また、Optuna が探索する `target_alpha` の範囲を 1.1〜1.9 に厳格に制限し、数値的安定性を確保しました。

### 4-3. Early Stopping の廃止と固定ラウンド学習への移行
不安定な早期終了を廃止し、`num_boost_round=500` の **固定ラウンド学習** へ切り替えました。代わりに、予測値の標準偏差を確認する健全性チェックを導入し、モデルが有意な差を出力しているかを監視する体制を整えました。

# 5. 最終的な解決策

数週間にわたる試行錯誤の末、**「穴馬除外の法則」**を確立した最終構成が完成しました。

### 最終的なシステム構成
- **アーキテクチャ**: `ranking_only_cols` による特徴量の物理的分離管理。
- **ハイパーパラメータ**: `num_leaves=127`, `feature_fraction=0.7`（正則化強化）の採用。
- **監視体制**: `rank_xendcg` を維持しつつ、学習監視を `rmse` で行うハイブリッド監視。

# 6. 学んだこと

今回の実験を通じて得られた教訓は、**「すべてのモデルにとって優れた『万能の特徴量』など存在しない」**ということです。
ランキングモデルを強化する「直近の安定性」は、穴馬モデルにおいては激走の予兆を覆い隠す有害なノイズへと変貌します。目的（1着予測 vs 期待値追求）に応じて特徴量空間を**「物理的に分離・統治」**することが、アンサンブル効果を最大化し、システムの収益性を死守するための生命線であることを痛感しました。

# 7. 次回予告

特徴量の多層分離により、ROI はついに大台の 90% を突破しました（単勝ベタ買い）。しかし、詳細な分析を進めると、オッズ 5倍以下の本命帯において、依然としてモデルが確率を過小評価する「構造的な校正歪み」が残っていることが判明しました。
